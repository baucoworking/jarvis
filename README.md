# JARVIS

**Just A Rather Very Intelligent System**

Asistente personal inteligente construido exclusivamente para Bau.

JARVIS está diseñado para acompañar a su usuario, comprender su contexto, ayudarlo a pensar, ejecutar acciones y evolucionar junto con él.

---

## Estado actual

### Fase 0 — Foundation

El proyecto se encuentra en la etapa de diseño y preparación de la arquitectura.

Todavía no se ha implementado el núcleo funcional de JARVIS.

---

## Objetivos principales

- Conversación por voz
- Memoria
- Contexto
- Personalidad
- Herramientas
- Control del PC
- Automatización
- Sistema de prioridades

## Filosofía

JARVIS no se construye para ser un producto.

Se construye para ser un sistema personal capaz de evolucionar durante años.

La tecnología puede cambiar.

La arquitectura puede evolucionar.

El propósito permanece.
