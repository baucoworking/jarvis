# JARVIS — Alcance

Este documento define qué pertenece al proyecto, qué pertenece al futuro y qué queda fuera de JARVIS.

## IN — Dentro del proyecto

Estas capacidades forman parte de la visión principal de JARVIS:

- Conversación por voz
- Memoria
- Contexto
- Personalidad
- Herramientas
- Control del PC
- Automatización
- Sistema de prioridades
- Gestión de tareas
- Integración con servicios personales

## LATER — Para el futuro

Estas capacidades pueden formar parte de JARVIS posteriormente, pero no son necesarias para construir el núcleo inicial:

- Casa inteligente
- Visión computacional
- Modelos de IA propios
- Wearables
- Robótica
- Integración con dispositivos físicos adicionales

## OUT — Fuera del proyecto

Estas capacidades no forman parte de los objetivos de JARVIS:

- Producto comercial
- Sistema SaaS
- Plataforma multiusuario
- Servicio destinado a venderse a terceros
- Armas
- Herramientas maliciosas

## Regla de alcance

Una nueva funcionalidad no debe incorporarse automáticamente al proyecto.

Antes de agregarla debe determinarse:

1. Si pertenece a la visión de JARVIS.
2. Si resuelve una necesidad real.
3. Si pertenece al alcance actual o a una etapa futura.
4. Si introduce una complejidad razonable para el beneficio que aporta.
