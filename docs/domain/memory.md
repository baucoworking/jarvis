# JARVIS — Memoria

## Objetivo

La memoria permite que JARVIS conserve y recupere información relevante a lo largo del tiempo.

La memoria debe distinguir entre información temporal, información persistente y diferentes tipos de conocimiento.

---

## Tipos de memoria

### Episódica

Representa acontecimientos o experiencias concretas.

Ejemplos:

- Una conversación
- Un proyecto iniciado
- Una reunión
- Una tarea realizada
- Algo que ocurrió en una fecha determinada

---

### Semántica

Representa conocimiento o información que JARVIS considera un hecho.

Ejemplos:

- Información sobre un proyecto
- Información sobre una persona
- Información aprendida durante una conversación
- Conocimiento relacionado con el usuario

---

### Preferencias

Representa preferencias relativamente estables del usuario.

Ejemplos:

- Preferencias de comunicación
- Preferencias de herramientas
- Preferencias de organización
- Preferencias personales

---

### Relaciones

Representa información sobre personas y relaciones relevantes para el usuario.

Ejemplos:

- Quién es una persona
- Qué relación tiene con el usuario
- Información relevante sobre esa relación

---

### Hechos

Representa afirmaciones concretas que JARVIS considera información relevante.

Los hechos deben poder distinguirse de opiniones, hipótesis o información temporal.

---

### Contexto

Representa información temporal necesaria para comprender una interacción actual.

El contexto no necesariamente debe convertirse en memoria permanente.

---

## Principios de memoria

- No toda información debe almacenarse permanentemente.
- No toda información almacenada debe recuperarse en todas las conversaciones.
- La memoria debe poder actualizarse.
- La memoria debe poder eliminarse.
- La memoria debe poder distinguir información permanente de información temporal.
- La recuperación de memoria debe considerar relevancia.
- La memoria debe permanecer bajo control del usuario.

---

## Implementación

Este documento define el concepto de memoria.

No define todavía la tecnología utilizada para almacenarla.

La base de datos, sistema de búsqueda y mecanismo de recuperación se decidirán posteriormente.
